待确认的一项行为

推荐：IPv4 / IPv6 优先。双栈 DNS 保留 A 与 AAAA 查询，TCP 使用 Xray Happy Eyeballs；UDP 不承诺自动回退。另一种方案为保留现有 ForceIPv4 / ForceIPv6 的域名解析限制，菜单标为“IPv4 出口 / IPv6 出口”，缺少所选地址族记录的域名可能无法访问。

新配置把默认直连出站放在第一项；显式 IPv4、IPv6 和 WARP 分流保留各自标签。已有配置修改前备份，校验失败不覆盖，服务恢复失败自动回滚。
